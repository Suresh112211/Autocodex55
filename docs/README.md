# AutoCodeX

World's Most Advanced, FREE, Unlimited App & Website Generator Platform.  
Zero-cost, AI-powered platform for building unlimited apps, websites, APKs & cinematic videos.  
No servers, no paid APIs, 100% lifetime free!

---

## Quick Overview

- Unlimited App & Website Generation
- Export APK (Expo EAS + GitHub Actions, 100% free)
- Export Website (Next.js, SEO, zip)
- Local AI Model Engines (Ollama, n8n)
- Self-healing, AI Auto Debug

---

## Get Started

1. Clone repo  
2. Setup `frontend` (`npm install`)  
3. Setup `backend` (`npm install`; n8n Desktop; Ollama)  
4. Use sample workflows in `/backend/n8n-workflows/`  
5. Run frontend, backend locally  
6. Export APK & Website using GitHub Actions

---

## Folders

- `frontend/` : UI, React/Next.js builder
- `backend/`  : n8n, AI engines, code-pipelines
- `.github/`   : Expo APK and Next.js zip workflows
- `assets/`    : Ready templates/starter packs
